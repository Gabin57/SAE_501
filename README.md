# Sign Scan (SAE 501)

Sign Scan est une application mobile de détection et de gestion de panneaux de signalisation routière. Ce projet s'inscrit dans le cadre de la SAE 501.

## Structure du Projet

- **scan_flutter/** : Application mobile développée avec [Flutter](https://flutter.dev/).
- **Documentation/** : Documentation technique et fonctionnelle du projet.
- **sonar/** : Fichiers de configuration pour l'analyse de qualité de code (SonarQube).
- **check_db.py** : Script utilitaire (Python) pour la vérification de la base de données.

## Fonctionnalités Principales

- **Détection temps réel** : Utilisation de la caméra pour identifier les panneaux de signalisation sur mobile et web.
- **Catégorisation** : Classement automatique des panneaux détectés (Danger, Interdiction, etc.).
- **Collection** : Enregistrement des panneaux scannés dans la collection de l'utilisateur.
- **Exploration** : Recherche et filtrage des panneaux existants.
